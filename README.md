# AI Resume Analyzer

## 📌 About

AI Resume Analyzer is a Django-based web application that analyzes resumes, calculates an ATS score, detects technical skills, identifies missing skills, matches resumes with job requirements, and provides personalized suggestions to improve resume quality.

The application allows users to upload their resumes in PDF format and receive an automated analysis through a professional dashboard.
