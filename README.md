# AI Resume Analyzer

## 📌 About

AI Resume Analyzer is a Django-based web application that analyzes resumes, calculates an ATS score, identifies skill gaps, matches resumes with job requirements, and provides suggestions to improve resume quality.

## 🚀 Tech Stack

* Python
* Django
* SQLite / MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap
* Git & GitHub

## ✨ Features

✅ User Registration & Login

## 🛠️ Installation

```bash
git clone https://github.com/bhanu-developer5161/AI-RESUME-ANALZER.git

cd AI-RESUME-ANALZER

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
